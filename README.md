# Química General · Guía para aprobar (UPCT, GIEyA)

Guía de estudio no oficial de Química General (1.º GIEyA, UPCT), construida a partir de los apuntes del profesor, las listas oficiales de preguntas teóricas de los dos parciales, la convocatoria del examen y los guiones de prácticas (curso 2021/22): 11 temas con «desde cero», fórmulas, método, trampas, problema resuelto y autoevaluación; figuras interactivas (átomo de Bohr, propiedades periódicas, Born-Landé, entrenadores de formulación, van der Waals, reactivo limitante, diagrama P-V, Le Chatelier, Clausius-Clapeyron, pila Daniell); 52 preguntas teóricas respondidas; 25 problemas resueltos paso a paso; todos los problemas de los apuntes con resultado; prácticas y formulario.

Web: https://helionacon-ui.github.io/Qu-mica-General/ · Índice de guías: https://helionacon-ui.github.io/GIEIA-UPCT/

Sitio estático (HTML + CSS + JS, MathJax desde CDN). Sin dependencias ni build.
